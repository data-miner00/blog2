# Blog

My blog and writings.

## Getting Started

1. Tested with Node.js v24.16.0
2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm start
```

4. Open `http://localhost:8080` in the browser.
5. Build for production:

```bash
npm run build
```

Artifacts at `_site/` folder.
